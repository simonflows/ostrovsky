# Островский. Купеческая Россия: Единство традиций

Интерактивный путеводитель по миру русского купечества и драматургии А. Н. Островского XIX века.

Проект разработан как библиотека-панорама к Дню народного единства.

## Основные разделы экспозиции

1. Уклад Замоскворечья: Между счётами и самоваром — быт, устои и сословные обычаи купечества.
2. Предметный мир и артефакты — интерактивная галерея артефактов эпохи (счёты, векселя, сундуки, ордера).
3. Карта невидимой Москвы: Топография Островского — исторические точки Москвы и Замоскворечья с архивными досье.
4. Книга-альманах: Эволюция драмы (1859 — 1878) — интерактивная книга с перелистыванием страниц и цитатами из пьес «Гроза» и «Бесприданница».
5. Драматургический излом: Женские судьбы — сопоставительный анализ образов Катерины Кабановой и Ларисы Огудаловой.
6. Замоскворецкий лексикон: Язык кошелька и совести — интерактивный словарь сословных терминов и понятий (Самодур, Купеческое слово, Долговая яма и др.).
7. Хронограф русского купечества (1850 — 1900) — хроника ключевых вех развития купеческого сословия.
8. Меценаты: Золотой век благотворительности — галерея великих меценатов России (Третьяковы, Морозовы, Бахрушины, Солдатенков).

## Стек технологий

- HTML5, CSS3 (Modern Flexbox, CSS Grid, 3D Transforms)
- Vanilla JavaScript (ES6+, Intersection Observer API)
- Полная адаптивность для мобильных устройств, планшетов и широкоформатных мониторов
- Отсутствие тяжелых внешних зависимостей (быстрая загрузка и автономность)
